## 复跑服务器测试

使用 JDK 25。测试入口默认关闭，仅在提供 `-PstarfallSmoke` 时启用；不会打包进正常运行 JAR。

1. 创建 `build/smoke-server`，在其中配置测试用 `server.properties`，至少设置 `server-ip=127.0.0.1`、独立端口，以及较小的视距。使用独立测试世界。
2. 阅读并接受 Minecraft EULA 后，在该目录的 `eula.txt` 设置 `eula=true`。
3. 可选：把 `energyexchange-mc26.2-0.3.5.jar` 放入该目录的 `mods`，附加验证 48 项价格。
4. 运行 `./gradlew -PstarfallSmoke runSmokeServer`。测试会修改该测试世界，并在断言结束后关闭服务器；失败或缺少完整成功报告时 Gradle 任务会失败。
5. 查看 `build/smoke-server/starfall-test-results.txt`。成功报告最后一行为 `ALL SERVER TESTS PASSED`。

## 验证范围边界

- 本次标准 Gradle/Loom 构建成功；不再需要上一版的直接编译替代流程。
- 服务器行为测试使用 Loom 开发运行环境；同时检查运行 JAR 的版本、资源完整性及测试模组隔离。
- 图形客户端、Mod Menu 鼠标操作、多人客户端视觉效果尚未实机验收。模型预览是 JSON 几何渲染，不是游戏截图；新增星形与爱心粒子的游戏内观赏效果仍需实机确认。
- 配方结构、解锁资源与价格经自动检查并由服务器加载；没有真实玩家手工逐项合成。
- PvP 和队伍保护沿用原版接口，未建立多玩家连接执行端到端对战测试。
