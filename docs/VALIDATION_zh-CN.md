- Minecraft Java 26.2，官方未混淆游戏类。

- Mod Menu 20.0.2：客户端编译依赖；未图形交互验收。

## 验证范围边界

- 当前环境的 Loom 平台探测尝试使用不允许的 Unix 套接字，因此没有宣称 `gradlew build` 在该环境成功。
- 交付 JAR 采用 JDK 25 直接编译、标准 JAR 打包；26.2 未混淆类无需旧版重映射。真实 Fabric 加载和服务器行为测试针对该打包方式完成。
- 图形客户端、Mod Menu 鼠标操作、多人客户端数据传输与视觉效果尚未实机验收。
- 物品升级、资源和价格通过自动检查；没有用真实玩家手工点击工作台逐项合成。
- PvP 和队伍保护由原版接口接入，未额外建立多玩家连接执行端到端对战测试。

不把以上未测试部分描述为已验证。游戏中的图形效果、兼容其他战斗模组和整合包经济仍适合在试玩中反馈。
